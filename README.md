# Wonder Robotics

The draft public site for Wonder Robotics, served by GitHub Pages from `main`.

- `index.html` is the page. Edit it directly.
- `wonder-robotics.html` is the same page as the Claude artifact source (no document wrapper); `index.html` = doctype + head wrapper + that file.
- `img/` holds the plates: the floor, kitchen and G1 from the 365 St Pauls Terrace Matterport capture, the service floor frame, and the Wonder Robotics lockup.

The page carries `noindex` while it is a draft for review.
